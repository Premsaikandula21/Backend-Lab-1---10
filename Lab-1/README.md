## Viva Questions

**1. What is the difference between `package.json` and `node_modules`?**
`package.json` holds project metadata, scripts and dependency declarations. `node_modules` holds the installed packages.

**2. What does `app.listen()` do?**
It starts the server listening for incoming HTTP requests on the given port.

**3. What do `req` and `res` represent?**
`req` is the incoming request (URL, headers, etc.). `res` is used to send the response and status code back to the client.
